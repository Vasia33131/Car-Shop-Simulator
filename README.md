# Car Shop Simulator

> 3D-симулятор автосалона: покупатели сами заходят в магазин, выбирают машину, стоят в очереди на кассе и платят.

## Об игре

Покупатели появляются у входа, проходят через автоматические двери, выбирают свободную машину, осматривают её и становятся в очередь. Над головой покупателя у кассы заполняется круговой индикатор оплаты, после этого цена машины начисляется игроку, над кассой всплывает «+$300», а машина считается проданной.

- **Цикл покупателя:** вход → выбор машины → осмотр → очередь → оплата → уход.
- **Бронирование машин:** два покупателя никогда не идут к одной машине.
- **Очередь на кассе:** по заданным точкам или автоматически за предыдущим покупателем.
- **Лимит покупателей** равен числу непроданных машин в зале.
- **Раздвижные двери** открываются, когда к ним подходит NPC.
- **Экономика:** баланс игрока, всплывающий текст из пула объектов, счётчик денег в UI.

## Управление

Перетаскивание мышью или пальцем двигает камеру по залу.

## Стек

Unity 2022.3.62f1 · C# · URP · uGUI + TextMeshPro · AI Navigation

## Архитектура

Код лежит в `Assets/Scripts`, пространство имён `StoreSim.*`:

| Папка | Что внутри |
|---|---|
| `NPC/Core` | `NpcActorBase` (базовый класс, по нему двери узнают NPC), настройки движения |
| `NPC/Movement` | `NpcMover`: собственное движение по точкам без NavMesh, с поворотами и покачиванием |
| `NPC/Customer` | `CustomerController` (полный цикл покупателя), `CustomerSpawner` (лимит активных покупателей) |
| `Shop` | `ShopManager` (список машин и выдача свободной с бронированием), `CarShopItem`, `CheckoutManager` (очередь и оплата), `ServiceSlider` |
| `Economy` | `EconomyManager` (доступ к балансу и событие `OnBalanceChanged`), `PlayerBalance` (хранение баланса в ScriptableObject) |
| `UI` | `BalanceDisplay`, `FloatingTextManager` с пулом объектов, `FloatingText` |
| `Environment` | `SlidingDoorByNpc` |
| `Camera` | Перемещение камеры перетаскиванием |

Решения:
- UI не опрашивает баланс каждый кадр, а подписывается на событие `OnBalanceChanged`.
- Машины сами регистрируются в `ShopManager` в `OnEnable`, их не нужно добавлять вручную.
- `ServiceSlider` сообщает о завершении и через `UnityEvent` в инспекторе, и через `Action` из кода.

## Запуск

1. Откройте проект в Unity 2022.3.62f1.
2. Откройте сцену `Assets/Scenes/SampleScene.unity` и нажмите Play.
